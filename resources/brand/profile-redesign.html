Profile — mobile redesign

Real Pewter tokens (resources/css/app.css). Redesign of resources/js/pages/Profile.tsx — layout only, no dev work yet. Same theme/viewport-switcher setup as Login and Today. Order kept as shipped: hero (voice + persona + stats) leads, then the race link, season/streak, pace targets, and the progression/journey chart — this page is a browsed reference, not a daily action loop, so nothing's collapsed behind a disclosure the way Today's supporting stats are.

What changed vs. the shipped page: same content and order, tightened for a phone-width single column instead of the desktop 2/5-column grids. "With Temari since" (desktop-only on the real page) now reflows in at the same 900px container-query threshold used everywhere else in this pass, rather than being permanently hidden below it. No bottom nav — Profile isn't a bottom-nav destination (it's reached by tapping the avatar elsewhere) so a nav with nothing lit up read as broken. A back chevron in the top bar replaces the brand lockup instead, matching how a pushed sub-page usually signals its way out. The profile/accessories/settings segmented tab strip is gone too — it mixed metaphors with the back chevron (tabs imply lateral siblings you switch between, back implies you drilled in and can leave). Settled on drill-down: Settings is now a single icon entry point in the top bar, its own pushed screen with its own back chevron home to Profile. Accessories (the collection/equip gamification) was explored as a separate mockup and dropped — not worth the ongoing maintenance cost — so it's gone from the nav entirely, not deferred.
