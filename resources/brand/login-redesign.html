Real Pewter tokens (resources/css/app.css). Redesign of resources/js/pages/Auth/Login.tsx — layout only, no dev work yet. Mockup-only exploration of light/dark/system: no CLAUDE.md or app.css change, the app stays light-only until this is a real decision. Same markup + CSS at every size below — the viewport switcher resizes all 3 theme frames at once (sizes match browser-review's own matrix); a container query reflows the layout past 900px, same threshold the real app's lg=1024 breakpoint effectively lands on once frame bezel/padding is subtracted.

What changed vs. the shipped page: hero + connect card now fit in one screen, no scroll needed to act. The two 3-card pitch grids collapsed into one compact list. The card-collectible showcase shrank to an inline teaser. Data-use + training-disclaimer merged into one collapsed disclosure. The duplicate bottom CTA card is gone — one connect action, not two. Dark mode reuses Sky (already Pewter's near-black) as the ground and Cream as text, so it needed zero new hex values — only role-swapping existing tokens.
