Settings — mobile redesign

Real Pewter tokens (resources/css/app.css). Redesign of resources/js/pages/Settings/Index.tsx — layout only, no dev work yet. Same theme/viewport-switcher setup as Login, Today and Profile. Order kept as shipped: notifications lead (what gets sent, where it goes), then running (HR zones), data-use, the fine print, and account at the very bottom.

What changed vs. the shipped page: everything condensed into one scrollable column instead of the desktop stacked cards — no structural changes. HR zones stay collapsed behind a disclosure by default, same convention as Today's supporting stats. The Telegram "bot unconfigured" edge case (an ops-only state, not a real user path) is left out of the toggle below — only not-connected vs. connected are shown. Settings has no standalone Strava connect/disconnect card on the real page either — that UI lives elsewhere (Activities empty states); the only Strava touchpoint here is the HR-zones resync action. No bottom nav — Settings is a pushed screen reached via the gear icon on Profile's top bar, so it gets a back chevron instead of a nav with nothing active. The profile/accessories/settings tab strip that used to sit under the headline is gone: mixing lateral tabs with a back chevron was a confused nav metaphor, so this pass commits to drill-down throughout instead. Accessories itself (the collection/equip gamification, explored as its own mockup) was dropped for maintenance cost — no longer part of the nav at all.
